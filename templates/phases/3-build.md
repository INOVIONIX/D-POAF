## Quick Start Guide

**Daily BUILD Workflow:**

1. **Check Dashboard** → Review current status and today's priorities
2. **Execute Actions** → Work with AI agents on planned Prompt Actions
3. **Track Progress** → Update status and deliverables as you go
4. **Handle Blockers** → Address issues quickly, ask for help
5. **Daily Sync** → Quick team alignment (async or meeting)

**Best Practices:**
- ✅ Update status frequently (not just at end of day)
- ✅ Test as you build, don't wait until the end
- ✅ Ask for help early when blocked
- ✅ Document decisions and changes
- ✅ Keep deliverables organized and accessible

**AI Collaboration Tips:**
- Clear prompts get better results
- Test AI output before marking complete
- Iterate on prompts if output isn't right
- Document successful prompt patterns for reuse

**This Phase Delivers:**
- Working features from your Feature Blocks
- Tested, quality code ready for integration
- Clear documentation of what was built
- Team experience with D-POAF® execution
- Ready-to-integrate deliverables
