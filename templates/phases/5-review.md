## Quick Start Guide

**PoV Session Process:**

1. **Prepare** → Review all deliverables and gather team
2. **Vote Individually** → Each person scores 1-10 on criteria
3. **Calculate Score** → Average all votes for final PoV score
4. **Make Decision** → Compare to threshold, discuss results
5. **Archive** → Document everything in WaveRegister
6. **Learn** → Capture lessons for next Wave

**Voting Tips:**
- ✅ Be honest - this helps improve future Waves
- ✅ Consider user impact, not just technical completion
- ✅ Vote independently first, then discuss
- ✅ Focus on value delivered, not effort spent

**Decision Guidelines:**
- **VALIDATED** → Ship it, celebrate, archive success
- **PARTIAL** → Document concerns, ship with caveats
- **REJECTED** → Fix issues, run another Wave if needed

**This Phase Completes:**
- Transparent team validation of work
- Honest assessment of value delivered  
- Immutable record of Wave results
- Clear lessons for continuous improvement
- Formal closure with team consensus
