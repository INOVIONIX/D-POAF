## 🚀 Quick Start Guide

**5 Steps to Plan Your Wave:**

1. **Pick Features** → Select 2-3 Feature Blocks®from backlog
2. **Define Actions** → Break each feature into DEV + TEST  + DOC actions  
3. **Estimate Time** → How long will each action take?
4. **Assign Roles** → Who's doing what?
5. **Check Ready** → All green? Start BUILD!

**Keep It Simple:**
- ✅ Focus on 2-3 features max per Wave
- ✅ Use simple action types (DEV, TEST, DOC)
- ✅ Estimate in hours, not story points
- ✅ One person per action for clarity

**This Gets You:**
- Clear plan everyone understands
- Realistic timeline and expectations
- Team aligned and ready to build
- Easy transition to BUILD phase
