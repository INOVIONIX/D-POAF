## Quick Start Guide

### Option 1: Start with One Template
Pick the template that solves your immediate need:
- **Feature unclear?** → Use Feature Block
- **Working with AI?** → Use AI Prompt  Action
- **Found a bug?** → Use Feedback
- **Team process issue?** → Use Team Rule

### Option 2: Start a Complete Wave
Follow this sequence for a full development cycle:
1. **Wave Setup** - INSTRUCT, PLAN, BUILD, INTEGRATE, REVIEW
2. **Feature Block(s)** - Define what to build
3. **AI Prompt(s) Action(s)** - Collaborate with AI
4. **Feedback** - Capture issues as they arise
5. **Wave Learning Log** - Reflect and improve

### Option 3: Pilot Program (Recommended)
Week 1-2: Feature Blocks + Feedback only
Week 3-4: Add AI Prompts Actions if using AI
Week 5-6: Add Wave Learning Logs
Week 7-8: Complete Wave cycle

## 📋 Template Guide

### **Feature Block** (`feature-block.md`)
**Purpose:** Define atomic work units with clear business value

**Key Sections:**
- **What & Why** - Problem and solution description
- **Value & Effort** - Simple 1-10 scoring for prioritization
- **Definition of Done** - Clear completion criteria
- **Technical Notes** - Implementation context

**Example ID:** `FB-AUTH-001`, `FB-PAY-015`
**Use when:** Planning any new feature or improvement

---

### **AI Prompt** (`prompt-action.md`)
**Purpose:** Effective AI collaboration instructions

**Key Sections:**
- **Goal** - What the AI should create
- **AI Instructions** - Clear, specific prompt text
- **Expected Output** - Files and quality standards
- **Notes & Refinements** - Learning for next time

**Example ID:** `PA-AUTH-001`, `PA-PAY-003`
**Use when:** Working with AI tools (ChatGPT, Claude, etc.)

---

### **Feedback** (`feedback.md`)
**Purpose:** Simple issue and improvement reporting

**Key Sections:**
- **What's the Issue** - Problem description
- **Impact & Priority** - Who's affected and how much
- **Proposed Solution** - Ideas for fixing
- **Notes & Learning** - Evidence and lessons

**Example ID:** `FD-2025-001`, `FD-2025-042`
**Use when:** Finding bugs, suggesting improvements, asking questions

---

### **Team Rule** (`team-rule.md`)
**Purpose:** Create team agreements and working standards

**Key Sections:**
- **Why Do We Need This Rule** - Problem being solved
- **The Rule** - Clear behavior expectation
- **Team Decision** - How the team agrees
- **Making It Work** - Implementation and review

**Example ID:** `TR-2025-001`, `TR-2025-008`
**Use when:** Team needs to agree on consistent practices

---

## 🔄 Learning & Improvement System

### **Wave Learning Log** (`wave-learning-log.md`)
**Purpose:** Capture lessons from each development cycle

**Key Sections:**
- **All Feedback from This Wave** - Links to individual feedback
- **Summary Numbers** - Quick metrics overview
- **Key Insights** - What worked, what was challenging
- **Action Plan** - Specific improvements for next Wave

**Use when:** End of each development cycle (weekly/bi-weekly)

### **Prompt Registerr** (`prompt-register.md`)
**Purpose:** Build library of effective AI prompts actions

**Key Sections:**
- **AI Prompts Used** - Track what worked well
- **Model Performance** - Compare different AI tools
- **Prompt Library** - Save best prompts for reuse
- **Team Feedback** - Collective learning

**Use when:** Team is actively using AI tools

### **Feedback Register** (`feedback-register.md`)
**Purpose:** Analyze patterns across multiple development cycles

**Key Sections:**
- **Cross-Wave Analysis** - Patterns between cycles
- **Recurring Issues** - Problems that keep appearing
- **Improving Trends** - Evidence of getting better
- **Project-Level Insights** - Systemic observations

**Use when:** After 2+ development cycles completed

## 🌊 Wave Development Cycle

### **Simple 5-Step Process**
| Step | Template | Purpose | Duration |
|------|----------|---------|----------|
| **1. INSTRUCT** | `instruct.md` | Gather context (RAG) and prepare team/AI | 15 min |
| **2. PLAN** | `plan.md` | Select Feature Blocks® and define Prompt Actions | 20 min |
| **3. BUILD** | `build.md` | Execute plan with AI collaboration | 60-80% of time |
| **4. INTEGRATE** | `integrate.md` | Test, validate, and refine deliverables | 15 min |
| **5. REVIEW** | `review.md` | Conduct PoV® session and archive results | 25 min |

### **Wave Types for Different Needs**
- **Standard Wave** - 8 hours max for feature development
- **Quick Wave** - < hours for small improvements
- **Learning Wave** - Focus on experimenting and learning

### 📂 Directory Explanation

#### 📋 **Project-docs/**
**Purpose:** Project documentation and templates  
**Contains:** README, D-POAF templates, guidelines  
**Who uses:** All team members, new joiners  
**Update frequency:** As needed for process improvements

#### 🎯 **Features/**
**Purpose:** Feature Blocks definitions and planning  
**Contains:** Feature definition, acceptance criteria, value scoring  
**Who uses:** Product team, Wave Captain, stakeholders  
**Update frequency:** During INSTRUCT and PLAN phases

#### 🤖 **AI-Prompt-Actions/**
**Purpose:** AI collaboration instructions and results  
**Contains:** Prompt Action templates, AI outputs, refinements  
**Who uses:** Wave Surfer, developers working with AI  
**Update frequency:** During BUILD phase, continuous refinement

#### 🔄 **Feedback/**
**Purpose:** Issue tracking and team agreements  
**Contains:** Bug reports, improvement suggestions, team rules  
**Who uses:** Entire team, Peace Guardian  
**Update frequency:** Continuous, as issues arise

#### 📚 **Learning**
**Purpose:** Knowledge capture and continuous improvement  
**Contains:** Wave retrospectives, AI tracking, best practices  
**Who uses:** Teams, RAGer, continuous improvement  
**Update frequency:** End of each Wave, quarterly reviews

#### 🗄️ **Wave-register/**
**Purpose:** Permanent record of all Wave activities  
**Contains:** Wave blocks, phase documentation, PoV results  
**Who uses:** Wave Captain, stakeholders, future reference  
**Update frequency:** Throughout Wave lifecycle, archived permanently

### **File Naming Patterns**
```
Feature Blocks:    FB-[MODULE]-[NUMBER]-[description].md
Prompt Actions:    PA-[MODULE]-[NUMBER]-[TYPE]-[description].md
Feedback:          FD-[YEAR]-[NUMBER]-[description].md
Team Rules:        TR-[YEAR]-[NUMBER]-[description].md
Wave Learning:     W-[NUMBER]-[MODULE]learning-log.md
Wave Blocks:       WRB-[YEAR]-[PROJECT]-W-[NUMBER].md
Proof of Value:    POV-[WAVE NUMBER]-[SCORE]-[SATE].md
```

### **Module Abbreviations**
```
AUTH = Authentication
PAY = Payment
USER = User Management
```

## 🎯 Usage Workflow

### **1. Starting a New Wave**
1. Create folder in `wave-phases/W-XXX/`
2. Use templates from `Project-docs/templates/`
3. Define Feature Blocks in `Features/`
4. Document in Wave Block (`Wave-register/wave-blocks/`)

### **2. During Development**
1. Create Prompt Actions in `AI-Prompt-Actions/`
2. Track issues in `Feedback/`
3. Update Wave phase files in `wave-phases/W-XXX/`

### **3. End of Wave**
1. Complete Wave Learning Log in `Learning/waves/`
2. Update AI tracking in `Learning/ai-tracking/`
3. Create PoV record in `proof-of-value/`
4. Archive Wave Block with final status

## 💡 Implementation Best Practices

### **Start Small**
- Begin with 1-2 templates that solve immediate pain points
- Add complexity gradually as team gets comfortable
- Focus on value over perfect process adherence

### **Keep It Simple**
- Fill templates honestly don't inflate scores or complexity
- Use plain language that your team understands
- Adapt templates to your context, don't be rigid

### **Build Habits**
- Make template use part of regular workflow
- Review and improve template usage regularly
- Celebrate when templates help solve real problems

### **Learn and Improve**
- Use learning logs to identify what's working
- Adjust processes based on real experience
- Share learnings with other teams

## 🔧 Progressive Enhancement Path

### **Phase 1: Basic Practices (Weeks 1-4)**
- Feature Blocks for planning
- Feedback for issue tracking
- Simple team rules as needed
- **Goal:** Build basic documentation habits

### **Phase 2: AI Collaboration (Weeks 5-8)**
- Add AI Prompts Actions if using AI tools
- Start AI Prompt Tracker
- Experiment with AI Model development
- **Goal:** Effective human-AI collaboration

### **Phase 3: Learning Systems (Weeks 9-12)**
- Regular Wave Learning Logs
- Project Feedback Register
- Pattern recognition across work
- **Goal:** Continuous improvement culture

### **Phase 4: Full Wave Cycle (Month 4+)**
- Complete Wave Instruct →  Plan → Build → Integrate → Review
- Wave Registers for knowledge sharing
- Cross-team learning and best practices
- **Goal:** Mature, self-improving team practices
