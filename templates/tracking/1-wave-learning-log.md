**Quick Start Guide:**
1. **During the Wave** - Team members create individual Feedback reports (FD-YYYY-XXX) when they find issues
2. **End of Wave** - Spend 30 minutes as a team filling this log with all Feedback from the Wave
3. **Link everything** - Reference Feedback IDs so you can find detailed reports later
4. **Look for patterns** - What keeps happening across Waves? What works well?
5. **Make it actionable** - Turn insights into specific action items for next Wave

**Tips for Project-Long Learning:**
- Create one log per Wave AND one overall project log (FeedbackRegister)
- Compare logs across Waves to see improvement trends
- Keep Feedback reports detailed, keep this log focused on key insights
- Use this to plan better Feature Blocks and AI Prompts Actions in future Waves
- Track which team rules actually help vs which ones don't

**When to Use This:**
- End of every Wave (W-001, W-002, etc.)
- After completing a major feature spanning multiple Waves  
- Monthly or quarterly project reviews to compare multiple Waves
- Before starting similar projects (review what worked)
