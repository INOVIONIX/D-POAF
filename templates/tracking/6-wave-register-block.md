# Wave Register Block Template

## Overview

This template creates a permanent record of everything that happened during a Wave. Think of it as the "permanent logbook" that gets stored in the D-POAF system and shared across all projects. This helps teams learn from each other and builds organizational knowledge.

**Use this when:** You complete a Wave and want to create a permanent, traceable record that other teams can learn from.

**How This Builds Organizational Knowledge:**
- **This Wave Register** gets stored permanently in the D-POAF system
- **All teams** can search past Wave Registers to learn from similar work
- **Patterns and solutions** get identified across multiple projects
- **Best practices** emerge from analyzing many Wave Registers together
- **Innovation spreads** as teams share what works

**Quick Start Guide:**
1. **Complete your Wave** using the other templates (Feature Blocks, AI Prompts Actions, etc.)
2. **Fill this Register** with the key outcomes and learnings
3. **Focus on helping future teams** - what should they know?
4. **Archive it** so other teams can find and learn from your experience
5. **Check other Registers** before starting new similar work

**This Register Connects To:**
- **Your Wave's** AI PromptRegister (Tracker), Learning Log, and FeedbackRegister (Reports) 
- **Other teams'** Wave Registers doing similar work
- **Organization-wide** pattern analysis and knowledge sharing
- **D-POAF evolution** through cross-project learning and improvement
